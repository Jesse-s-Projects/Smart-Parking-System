### Development Methodology

This project will follow an Agile development approach, with work completed incrementally throughout the project.

The team's process may be adjusted throughout the project based on project needs and lessons learned during development.

### Communication & Collaboration

The team will use Discord as its primary communication method.

Communication will be used to:
* Coordinate development activities
* Discuss requirements and design decisions
* Identify blockers
* Request assistance or review
* Coordinate integration between application components

Major design decisions and changes affecting multimple areas of the application should be discussed with the team before implementation.

### Task Management

Project tasks will be tracked using Trello.

Tasks should contain enough information for the assigned team member to understand the expected work.

The project will use the following general workflow:

Backlog -> To Do -> In Progress -> Done

Tasks may include labels, assignments, due dates, checklists, or other information where useful.

### Source Control

The project will use Git and GitHub for source control and collaborative development.

Team members should use direct pushes along with descriptive but concise commit messages.

Team members should pull the latest changes frequently to avoid conflicts with another team member's work.

### Documentation

Project documentation will be maintained alongside development and published using GitHub Pages.

Documentation will include relevant project information such as:
* Project proposal and overview
* Requirements Specification
* Project management processes
* System and database design
* Development/setup instructions

Documentation should be updated when significant changes make existing information innacurate.

### Progress Tracking

Project progress will be primarily measured through:
* Completion of tracked tasks
* Implementation of project requirements
* Working software functionality
* Git commits and repository activity
* Project demonstrations and course milestones

The team will periodically review current progress and adjust priorities or project scope as necessary to maintain an achievable project.
