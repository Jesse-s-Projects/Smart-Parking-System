### Problem Statement

#### Managing parking spaces in urban areas can prove challenging with errors in tracking vehicles, assigning parking spaces, and handling congestion.

### Objectives

1. Entry & Exit Monitoring
    * Monitor arrival and departure times of vehicles exiting/leaving the parking garage. Also, store relevant vehicle information, such as color, make, model, year, and license place number for security purposes.

2. Parking Duration & Fee Calculation
    * Display time elapsed in parking space, arrival and departure times, and fee amount in appropriate currency to user. If applicable, factors in damage fees and other penalties.

3. Mapping & Parking Availability
    * Create navigation system where user can view and select different floors and available parking spaces. If there is parking congestion, the system will estimate a time when to check back for available parking.

4. Generate Reports & Financial Insights
    * Generate and analyze monthly reports based on earnings and use insights to make decisions and improve the system.

5. Additional Features
    * Prompt users to submit feedback and describe and rate their experience, implement measures to prevent misuse, and securely store data using encryption methods.

### Key Features

* Real-time tracking for free parking spaces
* Search and filtering capabilities for workers to easily find preferred spots
* User checking to prevent non-workers access
* An interactive map to see which spots are available
* Admin dashboard for lot managers to manage system health
